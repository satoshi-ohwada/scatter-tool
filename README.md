# 散布図作成ツール (QuickScatter)

ExcelやCSVの表データから、**「平均値中心の4象限分割」「45度線」「1次回帰線」「重なり防止の引き出し線付きラベル」**を備えた高品質な散布図を手軽に作成・エクスポートできる完全ローカルWebアプリケーションです。

外部サーバーとの通信は一切行わず、お使いのPC（ブラウザ内）で完全に処理が完結するため、機密データや社内データも安全に取り扱えます。

## ✨ 特長

1. **Excelの手間をゼロにするワンクリック分析**
   - Excelでは作成に手間がかかる「平均十字線による4象限分割」や「45度線（y=x）」、「1次回帰直線（$R^2$、回帰式、信頼区間）」をチェックボックス1つで瞬時に描画します。
2. **ラベルの重なり自動回避 &amp; 他プロット点の保護（非遮蔽）**
   - データ点が多い場合に文字が重なる問題を解決。力学モデルによる自動衝突回避に加え、自動引き出し線（Leader Lines）を描画します。
   - **他プロット点遮蔽防止**: ラベル矩形（AABB）が自分自身以外のプロット点（○）を隠して見えなくしてしまう問題を、高精度な幾何学的衝突判定と16方向安全スライド探索によって完全に防止します。
   - さらに、マウスでラベルをドラッグ＆ドロップして自由に配置調整でき、引き出し線も追従します。
3. **一般的な縦横比 (4:3) & 小型ノートPC最適化レイアウト**
   - 散布図が横長に引き伸ばされて縦に潰れるのを防ぎ、標準的で最も見やすい **4:3 黄金比** を維持して自動フィットします。
   - 小さめのノートPC（1366×768等）でもスクロール不要で散布図と集計サマリー全体を一目で把握できます。
   - **「◀ パネルを隠す」**: 設定パネルを折りたたんで散布図を横幅いっぱいに拡大。
   - **「⛶ 全画面表示」**: ワンクリックで画面全体に散布図を特大表示（Escキーで復帰）。プレゼンや詳細確認に便利です。
4. **完全ローカル実行 (外部通信ゼロ・高セキュリティ)**
   - インターネット接続不要。外部CDNへの依存もなく、すべてのデータ処理と描画はブラウザ（JavaScript）内で完結します。
5. **Office・レポートに直結する高品質エクスポート**
   - **SVG（ベクター画像）**: PowerPointやWordに挿入しても文字がぼやけず、拡大・縮小も自由自在。
   - **高解像度PNG & クリップボード直接コピー**: 「画像をコピー」ボタンを押すだけで、そのまま資料に貼り付け可能です。

## 🚀 クイックスタート (ローカル起動)

Python 3 がインストールされている環境であれば、追加ライブラリのインストールなしで即座に起動できます。

```bash
# ターミナルで本ディレクトリに移動して実行
./serve.sh
# または
python3 serve.py
```

* 実行すると自動的にブラウザで `http://localhost:8000/index.html` が開きます。
* 8000番ポートが使用中の場合は、自動的に空きポート（8001〜）を検出して起動します。
* 終了するにはターミナルで `Ctrl + C` を押してください。
* ※Webサーバーを介さず、`index.html` を直接ブラウザにドラッグ＆ドロップして開くことでも動作します。

## 🔍 主要機能一覧

### 1. 簡単データ取り込み &amp; 対象行・列の選択・強調
* **ファイル形式**: CSV、TSV、Excel（`.xlsx`, `.xls`）のドラッグ＆ドロップ対応。
* **文字コード自動判別**: 日本のExcelから出力された **Shift_JIS (CP932)** および **UTF-8** を自動判別。
* **クリップボード直接貼り付け &amp; 常設ペースト入力枠**:
  - **サイドバーのタブ切替**: 「📁 ファイル読込」と「📋 コピペ貼り付け」をタブでワンクリック切替可能。コピペ枠へ直接貼り付けるだけで即座に解析・描画。
  - **画面全体での直接貼り付け**: Excelで表をコピー（Ctrl+C）し、画面上のどこでも `Ctrl+V` を押すか、初期画面中央の「📋 コピペで即時作成」をクリックするだけで瞬時にプロットを生成。
  - **ブラウザ権限自動フォールバック**: ブラウザのクリップボード権限設定により直接アクセスがブロックされた場合でも、自動的にコピペタブや貼り付けダイアログが開き、テキストエリア経由で100%確実に貼り付け可能。
  - **会計・統計記号の自動認識**: 日本の官公庁統計や決算データで多用されるマイナス表記（`▲1.5%`, `△320`, `(120)`）も自動的に負の数値として正規化。
* **自動クレンジング**: カンマ区切り数値（`3,200`）、パーセント表記（`12.5%`）、全角英数字を自動正規化。
* **📄 データ確認・対象設定モーダル**:
  - **作図対象列の選択**: モーダル上部のセレクタから、プロットに用いる「名称列」「X軸」「Y軸」を直接切り替え可能。テーブルヘッダーにも各軸の役割タグ（`X軸`, `Y軸`, `名称`）が明示されます。
  - **行ごとの作図対象選択（除外・復帰）**: 表の先頭にあるチェックボックスで、作図に含める行を個別選択。チェックを外した行は散布図プロットおよび統計（回帰直線・決定係数等）から即座に除外されます。
  - **個別ラベル表示指定（色は通常のまま名前のみ付与）**: 「🏷️ ラベル」列のチェックボックスで、点の色は通常のまま（象限カラーやテーマ色）、注目したい特定の点にだけ個別ラベルを表示可能。
  - **行の強調（ハイライト表示）**: 「★ 強調」チェックボックスにチェックを入れた行は、散布図上でプロット点（拡大＋コーラルオレンジ・白枠線）およびラベル（専用アクセント背景・太字・オレンジ枠線・強調引き出し線）が目立つように強調描画されます。
  - **一括操作ボタン**: 「☑ 全作図」「☐ 全解除」「🏷️ ラベルクリア」「★ 強調クリア」ボタンおよびヘッダーの全選択チェックボックスで大量のデータも素早く切り替え可能。
  - **リアルタイム検索 &amp; CSVコピー**: キーワードで即座に絞り込み、表全体をCSV形式でクリップボードへワンクリックコピー。

### 2. 分析補助線 (4象限・45度線・1次回帰線・周辺分布)
* **平均4象限分割**:
  - X軸・Y軸の「平均値」「中央値」「幾何平均（正の値のみ）」または「加重平均（ウェイト指定）」を基準に十字線を描画。メニュー内には用途に合わせた動的ヒント（外れ値対策、比率分析、規模重心など）が表示され、最適な代表値を迷わず選択可能。加重平均選択時のみ、対象とする重み属性（人口や数量など）を選択可能。
  - 各象限（Q1:青、Q2:黄、Q3:グレー、Q4:橙）のCUDに完全準拠した緑不使用・ビジネス資料に最適な洗練された淡色パステル背景と、象限名称ラベルの自由編集。
* **45度線 (y = x)**:
  - 2つの指標（例: 計画 vs 実績）の比較に便利な対角線。
  - 「軸スケール1:1固定」により、正しい45度アスペクト比を維持。
* **1次回帰線 (線形回帰)**:
  - 最小二乗法による単回帰直線を自動計算。
  - **回帰式・決定係数($R^2$)の表示切替 & 重なり防止**: グラフ上部ヘッダー（プロット枠外右上）に上品なミニマルバッジとして配置。第I象限（Q1）の象限ラベルや境界線、プロット点との重なりを根本的に防止。
  - **バッジのドラッグ移動 & 定位置リセット**: 回帰式バッジはマウスで掴んで自由な位置へドラッグ移動可能。ダブルクリックで右上の定位置へ即時復帰。
  - 95%信頼区間の帯（バンド）表示に対応（デフォルトOFF、必要な場合にワンクリックで表示可能）。
* **周辺分布 (マージナルヒストグラム &amp; KDE曲線)**:
  - X軸の上側・Y軸の右側の外側に、各変数の1次元分布（ヒストグラムおよびガウスカーネル密度推定 KDE曲線）を散布図と完全に同期させて描画。
  - **スタージェスの公式（$k = 1 + \log_2 n$）による階級数自動決定**: 統計学の国際標準（JIS Z 9041-1 / ISO 2602等）に基づき、有効データ件数から最適な階級数を自動判定して初期表示。プレゼンや報告時にも「統計学の標準則に基づき客観的に決定した」と説明可能。必要に応じてスライダーで任意の値にも手動調整可能。
  - 「ヒストグラム＋KDE曲線」「ヒストグラムのみ」「KDE曲線のみ」の表示切替に対応。
  - 散布図の2変数相関を見ながら、各軸単体での分布形状（単峰・多峰、歪み、ボリュームゾーン）を瞬時に把握可能。データ点が密集するオーバープロッティング時にも各軸の密度傾向が一目で分かります。

### 3. スマート・ラベル表示 &amp; 自動引き出し線
* **表示モード切替**: `全件表示` / `個別指定のみ表示（データ確認や点クリックで選択した点のみ）` / `外れ値のみ表示（平均から離れた重要プロット）` / `上位5件・10件` / `非表示（ホバー時のみ確認）`。
* **プロット点の直接クリックによるラベル切替**: 散布図上のプロット点をクリックするだけで、その点のラベル表示/非表示を即座にトグル可能。
* **自動衝突回避 &amp; 他プロット点非遮蔽保証**: ラベル同士の重なり回避だけでなく、自分自身以外のプロット点（○）を隠してしまわないよう、AABB矩形とプロット点の幾何学衝突判定に基づき安全な空き領域へ自動配置。
* **強調ラベルの優先配置 &amp; 決定論的重なり完全解消**:
  - 強調指定された項目（デモデータの青森県など）は、周囲の通常ラベルやプロット点よりも優先して特大の安全クリアランス（16px以上）を確保。
  - 力学モデル反復とポストプロセス（`resolveLabelCollisions`）により、密集ゾーンでも近接する通常ラベルを自動的に周囲（放射状）へ押し出し、強調ラベルと他ラベルとの重なりを100%防止。
* **自動引き出し線**: 点から離れたラベルには細い引き出し線を自動接続。
* **マウスドラッグ移動 & レスポンシブ相対維持**: 配置されたラベルや回帰式バッジをマウスでドラッグして直感的に微調整可能。プロット点に対する相対オフセットで保持されるため、全画面表示と通常表示を切り替えても配置関係が崩れません。ツールバーの「↺ リセット」ボタンでいつでも初期の自動最適配置・標準サイズに一括復帰できます。

### 4. 洗練されたデザイン &amp; 「見たまま」ベクター・高画質出力
* **作図領域の最大化 &amp; 右下ホバーサマリー**:
  - 常時場所を専有していた下部サマリーバーを撤廃し、画面下端まで作図領域を垂直方向に大きく拡大。
  - 統計情報（サンプル数、相関、回帰式、象限別内訳等）は、画面右下の小さな「📊 サマリー」バッジにマウスをホバーした時（またはクリック時）だけ展開するフロート表示に移行。
* **軸目盛りと項目名称の重なり防止 (動的マージン自動調整)**:
  - 縦軸（Y軸）：目盛り数値の桁数（1,000,000など）に応じて左側余白（`margin.left`）を動的に自動計算。数値の左端から常に一定の余白を保って項目名称を配置し、目盛りとの重なりを根本的に防止。
  - 横軸（X軸）：目盛り数値と項目名称の間に十分なクリアランスを確保し、下部余白（`margin.bottom`）とタイトルの配置を最適化。
* **標準縦横比 (4:3) 自動フィット &amp; 全画面「見たまま」出力**:
  - 横長画面でも縦に潰れない標準縦横比（4:3、軸1:1固定時は正方形）を維持。
  - 小型ノートPCでも画面いっぱいに散布図が大きく広がり、細部まで一目で把握可能。
  - ツールバーの「⛶ 全画面表示」で画面いっぱいに広げてラベル配置を快適に調整可能。全画面表示ツールバーから画面を縮小することなく**調整した「見たままの形・大迫力解像度」で直接PNG・SVG保存**できます。
* **デザインテーマ**:
  - `Modern Navy`（ビジネス報告向け・標準）
  - `Fresh Emerald`（清潔感のあるグリーン）
  - `Vibrant Purple`（プレゼンテーション用・高コントラスト）
  - `Academic Monochrome`（論文・白黒印刷用）
* **半透明プロット**: 重なりが濃淡で自然にわかるアルファブレンド表示。
* **直感的なボタン配置 &amp; 出力機能 (プレビューツールバーに一元化)**:
  - アプリヘッダーには「📄 データ確認」のみをすっきり配置し、無駄なタグや重複を排除。
  - グラフの操作・保存ボタンは散布図直上のツールバーに集約され、通常時も全画面時も同じ場所で迷わず操作可能。
  - `📋 画像をコピー`: 現在画面で見えている形そのままの高解像度PNGをクリップボードにコピー（PPT/Excelへ直接ペースト可能）。
  - `💾 PNG保存`: 現在の画面ビュー・アスペクト比を維持した2倍解像度（Retina品質）のPNG保存。
  - `📐 SVG保存`: IllustratorやOfficeで拡大縮小・文字編集が可能な自立型ベクター画像（SVG 1.1規格完全準拠・サニタイズ処理により、IllustratorやPowerPoint、Inkscape等でのラベル背景黒塗りバグを完全解消）。
  - `📋 サマリーコピー`: 相関係数、回帰式、各象限または各クラスターに属するアイテム一覧をテキストで取得。

### 5. クラスター分析 (K-Means & 標準化散布図)
* **Zスコア標準化散布図への即時切り替え**:
  - クラスター分析を有効化すると、X軸・Y軸がそれぞれの平均0・標準偏差1に揃えられた**「Zスコア標準化散布図」**に切り替わります。
  - 単位や数値の桁数が大きく異なる2指標であっても、重要度を1:1に対等に評価した幾何学的クラスタリングが行われます。
* **適正クラスター数の自動推定 (シルエット係数)**:
  - データの自然な塊（凝集度と乖離度）を評価する**シルエット分析**により、データに最も適したクラスタ数 $k$ を自動算出・推奨バッジとして提示。
  - ステッパーボタン（`−` / `＋`）により、いつでも直感的にクラスタ数を増減してシミュレーション可能。
* **CUD準拠グループ色分け &amp; 重心・信頼楕円表示**:
  - 各クラスターを判別の容易なカラーパレットで自動塗り分け。
  - 各グループの重心（Centroid: `C1`, `C2`...）および分布の広がり・主軸方向を包み込む**半透明の信頼楕円（エラー楕円）**をリアルタイム描画。
* **回帰直線・統計の自動連動 (シンプソンのパラドックス防止)**:
  - 複数グループが混在する空間で全体を1本の直線で結ぶことによる誤認を防ぐため、クラスター分析モード有効化時は自動的に回帰直線のチェックが外れます（クラスター分析解除時に元の状態へ自動復元）。
* **生データとZスコアの二重情報ツールチップ**:
  - プロット点にホバーすると、所属クラスター名とともに元の生データ値（例: 520万人）と標準化Zスコア（+1.45σ）の両方を同時に確認可能。
